## 🚀 Getting Started

### First Time Setup

1. **Open the Application**
   - Double-click `index.html` to open in your browser
   - Or right-click → Open with → Choose your browser

2. **Understand the Interface**
   - **Top Section**: Statistics and theme controls
   - **Middle Section**: Task input and filters
   - **Bottom Section**: Your task list

3. **Create Your First Task**
   - Click the input field at the top
   - Type "My first task"
   - Press `Enter` or click "Add Task"
   - 🎉 Congratulations! You've added your first task

## 📝 Basic Features

### 1. Adding Tasks

#### Quick Add (Fastest Method)
1. Click the input field or press Tab to focus
2. Type your task description
3. Press `Enter`

**Example**: 
```
Type: "Buy groceries" → Press Enter ✅
```

#### Detailed Add (With Metadata)
1. Type your task description
2. Select priority level (Low/Medium/High)
3. Choose category (Work/Personal/Urgent)
4. Set due date (optional)
5. Set due time (optional)
6. Click "Add Task" or press Enter

**Example**:
```
Task: "Finish project report"
Priority: High
Category: Work
Due Date: 2024-12-15
Due Time: 17:00
→ Click "Add Task" ✅
```

**Tips for Good Tasks**:
- ✅ "Review chapter 3 of marketing book"
- ✅ "Email client about project update"
- ❌ "Work" (too vague)
- ❌ "Do stuff" (not actionable)

---

### 2. Completing Tasks

#### Mark as Complete
- **Click the checkbox** next to the task
- Task will show with strikethrough text
- Task appears faded
- Completion count increases

#### Mark as Incomplete
- **Click the checkbox again** to uncheck
- Task returns to normal appearance
- Useful if you marked something by mistake

**Visual Feedback**:
```
Before: ☐ Buy groceries
After:  ☑ Buy groceries  (faded, strikethrough)
```

---

### 3. Editing Tasks

#### Edit Task Text
1. Click the **"Edit"** button on any task
2. A dialog box appears with current text
3. Modify the text
4. Click **OK** to save
5. Click **Cancel** to discard changes

**Example**:
```
Original: "Buy milk"
Edited:   "Buy milk and bread"
```

**Note**: Currently, you can only edit the task text. Priority, category, and due dates must be set when creating the task.

---

### 4. Deleting Tasks

#### Delete Single Task
1. Click the red **"Delete"** button
2. Confirm the deletion in the popup
3. Task is permanently removed

**Warning**: ⚠️ This action cannot be undone!

**Best Practice**:
- Complete tasks instead of deleting them
- Keep a record of what you've accomplished
- Only delete duplicate or mistake entries

---

### 5. Filtering Tasks

#### Available Filters

**All (Default)**
- Shows every task in your list
- Useful for overview of everything

**Active**
- Shows only incomplete tasks
- Focus on what needs to be done
- Hide completed tasks from view

**Completed**
- Shows only finished tasks
- Review your accomplishments
- Identify completed items

**High Priority**
- Shows only high-priority tasks
- Focus on urgent items
- Ignore low-priority tasks

#### How to Use Filters
1. Click any filter button above the task list
2. The active filter is highlighted
3. Task list updates instantly
4. Filter remains active until changed

**Workflow Example**:
```
Morning: Use "Active" to see your to-do list
Evening: Use "Completed" to review your day
```

---

### 6. Searching Tasks

#### Real-Time Search
1. Click the search box (or press `Ctrl+F`)
2. Start typing
3. Tasks filter as you type
4. Results update instantly

**Search Tips**:
- Search is case-insensitive
- Searches task text only
- Combines with active filter
- Clear search to see all tasks

**Examples**:
```
Search "meeting" → Shows all tasks with "meeting"
Search "project" → Shows tasks containing "project"
```

## 🎯 Advanced Features

### 1. Priority System

#### Priority Levels

**🔴 High Priority**
- Urgent tasks requiring immediate attention
- Red color indicator
- Use sparingly for truly urgent items
- Examples: "Submit tax returns by Friday", "Fix critical bug"

**🟡 Medium Priority** (Default)
- Normal, everyday tasks
- Orange color indicator
- Most tasks should be medium priority
- Examples: "Write weekly report", "Plan next meeting"

**🟢 Low Priority**
- Nice-to-have tasks, no deadline
- Green color indicator
- Can be deferred if needed
- Examples: "Organize desk", "Read industry article"

#### Visual Indicators
Each task has a colored bar on the left:

🔴 | ☐ Critical task - do first!
🟡 | ☐ Normal task - do today
🟢 | ☐ Optional task - do when free

### 4. Drag & Drop Reordering

#### How to Reorder

**Desktop**
1. Click and **hold** on any task
2. **Drag** to new position
3. See preview of new location
4. **Release** to drop in place
5. Order saves automatically

**Visual Feedback**:
- Dragged task becomes semi-transparent
- Other tasks shift to show where it will drop
- Smooth animation on drop

**Use Cases**:
- Put urgent tasks at the top
- Group related tasks together
- Organize by workflow order
- Personal preference sorting

**Tips**:
- Drag from the main task area (not buttons)
- Order persists across sessions
- Works with filtered views
- Changes save immediately

## 💡 Tips & Tricks

### Productivity Tips

#### 1. The 2-Minute Rule
- If a task takes < 2 minutes, do it immediately
- Don't add it to your list
- Saves time and mental energy

#### 2. Daily Review
**Morning** (5 minutes)
- Review active tasks
- Drag most important to top
- Set realistic daily goals

**Evening** (5 minutes)
- Mark completed tasks
- Review what's left
- Plan tomorrow

#### 3. Weekly Cleanup
Every Friday or Sunday:
- Review all completed tasks
- Delete unnecessary items
- Archive old completed tasks
- Plan next week

#### 4. Priority Management
**Eisenhower Matrix**:
```
High Priority = Urgent + Important
Medium Priority = Important, not urgent
Low Priority = Not urgent, not important
```

#### 5. Task Breakdown
Large task: "Plan vacation"

Break it down:
- ✓ Research destinations
- ✓ Check flight prices
- ✓ Book hotel
- ✓ Create itinerary
- ✓ Pack bags

### Organization Tips

#### 1. Use Consistent Naming
```
✅ Good:
- "Email John about Q4 report"
- "Review chapter 5 notes"
- "Buy: milk, eggs, bread"

❌ Avoid:
- "Email" (too vague)
- "Read" (incomplete)
- "Stuff to buy" (unclear)
```

#### 2. Category Strategy
```
Work hours: Filter by "Work" category
After hours: Filter by "Personal" category
Emergency: Use "Urgent" category
```

#### 3. Priority Guidelines
```
Max 3 high-priority tasks per day
Most tasks should be medium
Low priority for "someday" items
```

#### 4. Due Date Strategy
```
Hard deadline: Set exact date
Soft deadline: No date needed
Recurring: Add multiple instances
```

## 🐛 Troubleshooting

### Common Issues

#### Issue 1: Tasks Not Saving

**Symptoms**:
- Tasks disappear after closing browser
- Changes don't persist

**Solutions**:

1. **Check Browser Settings**
   ```
   Chrome: Settings → Privacy → Site Settings → Cookies
   Enable: "Allow sites to save and read cookie data"
   ```

2. **Disable Private Browsing**
   - LocalStorage doesn't work in Incognito/Private mode
   - Use normal browser window

3. **Check Storage Quota**
   ```
   F12 → Application → Local Storage
   Check if storage is full
   Clear old data if needed
   ```

4. **Try Different Browser**
   - Test in Chrome, Firefox, or Edge
   - Helps identify browser-specific issues

---

#### Issue 2: Drag and Drop Not Working

**Symptoms**:
- Can't drag tasks
- Tasks snap back to original position

**Solutions**:

1. **Update Browser**
   - Ensure using latest version
   - Chrome 90+, Firefox 88+, Safari 14+

2. **Clear Cache**
   ```
   Windows: Ctrl + Shift + R
   Mac: Cmd + Shift + R
   ```

3. **Check JavaScript**
   ```
   F12 → Console
   Look for errors
   ```

4. **Disable Extensions**
   - Try disabling browser extensions
   - Some extensions interfere with drag/drop

---

#### Issue 3: Search Not Working

**Symptoms**:
- Search doesn't filter tasks
- No results shown

**Solutions**:

1. **Check Search Box**
   - Click search box to ensure it's focused
   - Try typing again

2. **Clear Search**
   - Delete all text from search box
   - Tasks should reappear

3. **Refresh Page**
   ```
   Windows: F5 or Ctrl + R
   Mac: Cmd + R
   ```

4. **Check Console**
   ```
   F12 → Console
   Look for JavaScript errors
   ```

---

#### Issue 4: Styling Looks Broken

**Symptoms**:
- Layout is messy
- Colors are wrong
- Elements overlap

**Solutions**:

1. **Hard Refresh**
   ```
   Windows: Ctrl + Shift + R
   Mac: Cmd + Shift + R
   ```

2. **Check File Structure**
   ```
   Ensure all three files are in same folder:
   ✓ index.html
   ✓ style.css
   ✓ script.js
   ```

3. **Clear Browser Cache**
   ```
   Chrome: Settings → Clear browsing data
   Select: Cached images and files
   ```

4. **Check CSS Link**
   - Open index.html in text editor
   - Verify: `<link rel="stylesheet" href="style.css">`

---

#### Issue 5: Dark Mode Not Persisting

**Symptoms**:
- Theme resets on page reload
- Always opens in light mode

**Solutions**:

1. **Enable LocalStorage**
   - Check browser privacy settings
   - Allow local data storage

2. **Re-toggle Theme**
   - Switch to dark mode
   - Close and reopen browser
   - Should persist now

3. **Check Console**
   ```
   F12 → Console
   Look for storage errors
   ```

---

### Performance Issues

#### Slow Performance

**If app feels sluggish**:

1. **Reduce Task Count**
   - Delete old completed tasks
   - Keep list under 500 tasks

2. **Clear Browser Data**
   - Clear cache and cookies
   - Restart browser

3. **Close Other Tabs**
   - Free up system memory
   - Close unused applications

4. **Update Browser**
   - Use latest browser version
   - Better performance and features

## ❓ FAQ

### General Questions

**Q: Is TaskMaster Pro free?**
A: Yes! Completely free for personal and commercial use.

**Q: Do I need to create an account?**
A: No. No account, no login, no registration needed.

**Q: Does it work offline?**
A: Yes! Works 100% offline. No internet connection required.

**Q: Where is my data stored?**
A: All data is stored locally in your browser using localStorage.

**Q: Can I access my tasks on different devices?**
A: No. Data is stored per-browser, not synced across devices.

---

### Features

**Q: How many tasks can I add?**
A: Typically thousands, limited only by browser storage (~5-10 MB).

**Q: Can I add subtasks or notes?**
A: Not in version 1.0, but planned for future versions.

**Q: Can I share tasks with others?**
A: Not currently. Each user has their own separate task list.

**Q: Can I export my tasks?**
A: Not yet, but export/import is planned for version 1.1.

**Q: Can I undo a deletion?**
A: No. Deleted tasks are permanently removed. Use the complete feature instead.

---

### Technical Questions

**Q: What browsers are supported?**
A: Chrome 90+, Firefox 88+, Safari 14+, Edge 90+, Opera 76+.

**Q: Do I need internet to use it?**
A: No. Works completely offline once loaded.

**Q: Is my data secure?**
A: Yes. All data stays on your device. Nothing is transmitted online.

**Q: Can I customize the colors?**
A: Yes! Edit the CSS variables in style.css.

**Q: Will future updates delete my data?**
A: No. Updates preserve existing data.

---

### Troubleshooting

**Q: Why did my tasks disappear?**
A: Possible causes:
- Used private/incognito mode
- Cleared browser data
- Switched browsers
- LocalStorage disabled

**Q: Why can't I drag tasks?**
A: Ensure:
- Using modern browser
- JavaScript is enabled
- Browser is up-to-date

**Q: Why is dark mode not saving?**
A: Check localStorage is enabled in browser settings.
